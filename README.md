# 🛡️ Cyber Secure To-Do List Application

A modern, high-performance web application designed with a sleek Cyberpunk UI and advanced frontend security practices. This project was developed as a final semester college submission to demonstrate secure web development concepts.

## 🔗 Live Demo
You can check the live working project here:
👉 [https://soni-frontend.github.io/To-Do-List-App/](https://soni-frontend.github.io/To-Do-List-App/)

## 🚀 Key Features

* **Cyberpunk Tech UI:** Implemented a stunning dark-mode interface using modern CSS gradients, glassmorphic design (`backdrop-filter`), and customized interactive components.
* **XSS (Cross-Site Scripting) Protection:** Integrated strict security measures by utilizing `textContent` instead of `innerHTML` during dynamic DOM manipulation to prevent malicious script injections.
* **Persistent Storage:** Uses browser `localStorage` to securely retain user tasks across sessions without data loss.
* **Responsive & Optimized:** Clean, modern layout with perfect spacing, interactive delete/add workflows, and smooth animation transitions.

## 🛠️ Tech Stack Used

* **Frontend:** HTML5, CSS3 (Modern Variables & Layouts)
* **Scripting:** Vanilla JavaScript (ES6+)
* **Icons:** Font Awesome Icons
